# Alaa Maged Mubarak — Portfolio

Static one-page portfolio. `index.html` is generated from the Claude Design source `design.dc.html`:

```bash
node build.mjs
```

No build tools or dependencies; host the folder as-is (GitHub Pages, Vercel, Netlify).

The "Download CV" button expects `Alaa_Maged_Mubarak_CV.pdf` in the root. Add it before publishing.
